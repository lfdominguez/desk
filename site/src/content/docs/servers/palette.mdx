<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd> (<kbd>⌘</kbd>+<kbd>K</kbd> on macOS), or
**Commands** at the right of the toolbar, opens the infra workspace's palette: one search box
for its sessions, servers, groups, organizations, runbooks, alerts and actions.

## Using it

- Type to search. It uses the [fzf syntax](/board/search/): fuzzy words, `'exact`,
  `^prefix`, `!not`. Matched letters are highlighted, best matches first.
- **↑ ↓** move, **↵** opens, **esc** closes.
- **Tab** and **Ctrl+Shift+Tab** switch scope: **All**, **Sessions**, **Hosts**, **Groups**, **Orgs**,
  **Runbooks**, **Alerts**, **Actions**, **Themes**. Only scopes with something in them show.
- On a wide window, a preview on the right shows the selected item: a server's address, group,
  alert, notes and open tabs; a session's organization, group, panes and state.

## What it lists

These show with an empty query:

| Group | An item reads | Opening it |
|---|---|---|
| Alerts | investigate CRITICAL web-02 | Makes the alert a card on the board, to look into. See [Alerts](/orgs/alerts/). |
| Sessions | Globex › web › web-01, Globex › Claude | Goes to that tab. "▲ needs approval" marks one waiting on you. |
| Runbooks | Rotate the billing logs | Runs it with this tab's Claude. See [Runbooks](#runbooks). |
| Orgs | Globex, "Claude for the org" | The organization's own Claude session. |
| Groups | Globex › web, "group view" | The [group view](/servers/overview/#group-view). |
| Hosts | Globex › db › db-02, "open ssh tab" | Opens a tab on the server, or goes to its session. |

A session or tab of another organization takes desk there: the Servers view follows.

## Runbooks

The palette lists the runbooks in `<Org>/.desk/infra/runbooks/` of the tab's organization,
with "run with Claude" and the file.

<figure class="cut">

![The palette with "rotate": the runbook Rotate the billing logs, "run with Claude · rotate-billing-logs.md"](../../../assets/shots/srv-palette-rotate-box.png)

<figcaption>A runbook, found by its title.</figcaption>
</figure>

Pick one and the tab's Claude follows it step by step ("▶ runbook: …" in the conversation). If
Claude is busy, desk says so: start it when Claude is done, or stop it. How to write one:
[Runbooks](/servers/infra-claude/#runbooks).

## Port forwards

Type a forward and pick it. It's added to the focused server's shared SSH connection, so no new
login, and it comes back after a reconnect or a restart. It lives as long as that connection:
closing the server's last pane ends it a minute later.

<figure class="cut">

![The palette with "forward 5432": localhost:5432 → localhost:5432 via web-01](../../../assets/shots/srv-palette-forward-box.png)

<figcaption>The palette says what the forward will do before you pick it.</figcaption>
</figure>

| You type | What you get |
|---|---|
| `forward 5432` | `localhost:5432` here reaches port 5432 on the server. |
| `forward 9000:5432` | `localhost:9000` here reaches port 5432 on the server. |
| `forward 9000:db.internal:5432` | `localhost:9000` here reaches `db.internal:5432`, through the server. |
| `rforward 3000` | Port 3000 on the server reaches port 3000 on this machine. |
| `socks 1080` | A SOCKS proxy on `localhost:1080`, through the server. |

`fwd` works for `forward`. Typing just `forward`, `rforward` or `socks` shows these forms as
hints. Each active forward is listed as **stop forward …**, to remove it.

## Files

**New directory split (files)**, <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> or the toolbar's
folder button opens a two-panel file manager under the panes: the focused pane's server on the
left (in the shell's current directory), this machine on the right. It works over SFTP on the
server's shared SSH connection, so no new login. A server without the sftp subsystem still
works: desk then runs `sh`, `ls`/`find`, `cat` and `tar` there, so the server needs nothing
installed. Copies keep each file's permissions. One split per tab. On Windows, a local pane's
split browses this machine on both sides, with Windows paths, and desk does its copies itself
(no `sh` there). **Chmod** there takes octal (`644`) and symbolic modes (`u+x`, `go-w`, `a=rX`)
as on Linux, but Windows files have no permission bits, only a read-only flag: removing the
owner's write (`u-w`, `a-w`, `444`) makes a file read-only, giving it back (`u+w`, `644`) clears
that, and the rest of a mode changes nothing.

| Key | What it does |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>PgUp</kbd> <kbd>PgDn</kbd> <kbd>Home</kbd> <kbd>End</kbd> | Move |
| <kbd>Tab</kbd> | The other side |
| <kbd>Enter</kbd> or <kbd>F3</kbd> | Open a folder, or download a file and open it |
| <kbd>Backspace</kbd> | Up a folder |
| <kbd>Space</kbd>, <kbd>Ctrl</kbd>+arrows, <kbd>Ctrl</kbd>+click | Mark |
| <kbd>A</kbd> | Mark or unmark all |
| <kbd>H</kbd> or <kbd>.</kbd> | Show dotfiles |
| <kbd>R</kbd> | Reload |
| <kbd>F4</kbd> | Edit in your editor: each save is uploaded back, for an hour |
| <kbd>F5</kbd> / <kbd>F6</kbd> | Copy / move to the other side |
| <kbd>F2</kbd> | Rename |
| <kbd>F7</kbd> | New folder |
| <kbd>F9</kbd> | Chmod |
| <kbd>F8</kbd> or <kbd>Delete</kbd> | Delete (asks first) |
| <kbd>Esc</kbd> | Cancel a copy, or close the split |

- Drag rows to the other side to copy them. Typing a name jumps to it.
- When a copy meets a file that's there already: <kbd>O</kbd> replaces, <kbd>S</kbd> skips,
  <kbd>N</kbd> cancels.
- With **F4**, if the server's copy changed since you opened it, desk asks before uploading.

## Sharing a pane

To show a terminal in a video call without sharing your whole screen:

- **share the terminal as a camera** makes a webcam called "desk terminal" that shows the
  focused pane (1280×720). Pick it as your camera in the call. It uses v4l2loopback when it's
  loaded, or else PipeWire. Linux only.
- **share the terminal as a screen** opens a window, "desk terminal share", that shows the
  focused pane. Share that window from the call. On Hyprland desk also makes a headless monitor,
  `DESK-SHARE`, so the call's screen picker lists it as a screen.

Both are view-only: nobody in the call can type. **stop the terminal camera** and
**stop sharing the terminal as a screen** end them.
