## Open it

- Select the card and press <kbd>E</kbd>.
- Right-click the card and choose **Edit card**.
- Click the pencil in the card's [session panel](/sessions/panel/).

Archived cards can't be edited. [Restore](/board/archive/#restore-a-card) them first.

## It saves when you close it

There's no Save button. Your changes are kept when the editor closes:

- <kbd>Esc</kbd>, or the **×** in its header;
- a click on the board beside it;
- <kbd>Enter</kbd> in a one-line field (title, organization, folder, due, labels), or <kbd>Ctrl</kbd>+<kbd>Enter</kbd> anywhere.

If a field doesn't check out, the editor stays open and a toast says why: an empty
title, a due date that isn't `YYYY-MM-DD`, an organization or folder that doesn't
exist, or a link desk can't read.

## The header

<figure class="cut">

![The editor's header buttons: Open session, Claude Code terminal, Delete and Close](../../../assets/shots/cards-editing-head.png)

<figcaption>Open session, Claude Code terminal, Delete, Close.</figcaption>
</figure>

| Button | Does |
|---|---|
| **Open session** | saves, closes the editor and opens the card's [session panel](/sessions/panel/) |
| **Claude Code terminal** | saves, closes the editor and opens the card's [terminal](/sessions/terminal/) |
| **Delete** (<kbd>Ctrl</kbd>+<kbd>Backspace</kbd>) | deletes the card. The toast's **Undo** (<kbd>Ctrl</kbd>+<kbd>Z</kbd>) puts it back where it was, for six seconds |
| **Close** (<kbd>Esc</kbd>) | saves and closes |

## The fields

<figure class="cut">

![Status: Backlog, To do (lit), In progress, Blocked, Done; Organization Acme, starting in ~/Work/Acme/api, with change organization and ↑ up; Folder api; Priority with Medium lit](../../../assets/shots/cards-editing-props.png)

<figcaption>Status, Organization, Folder and Priority.</figcaption>
</figure>

- **Title**: what the card is called, on the board and in its session.
- **Status**: the card's column, Backlog to Done (Review included). Click another to move it there when the editor closes.
  Moving a card out of Review into Done is how you sign off Claude's work.
- **Organization**: the organization the session runs in. Type to filter, or pick one. Under it,
  desk shows where the session starts and the subfolders matching the Folder field.
  See [New card](/cards/new-card/#the-organization-and-folder).
- **Folder**: a folder inside the organization, or nothing for the organization's own folder.
- **Agent**: only when the organization has Claude Code agents. See [The canvas](/sessions/canvas/).
- **Priority**: None, Low, Medium or High. It's the colored stripe on the card's left edge.
- **Due**: a date, `YYYY-MM-DD`. Beside it, desk shows the day ("Thu, Nov 5"), and "overdue" once it's past.
- **Labels**: comma separated (`api, billing`).
- **Links**: the card's links, each with its live state, then a field with their
  URLs, one per line. Add a URL or a Jira key there, or delete a line to remove that link. See [Links](/cards/links/).
- **Notes**: what the card is about, in Markdown. They read formatted. Click them to edit the text.

:::note
A session's first message carries the card's title, notes and links. Editing
them later doesn't change what the session already read. Tell Claude in the session if it matters.
:::
