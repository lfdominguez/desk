The Settings dialog edits two kinds of files: desk's own settings (the folders it searches and the
languages) and each organization's `desk.toml` (its accounts).

![The Settings dialog on Acme's page: the nav on the left, Acme's GitHub and Jira accounts, the buttons that add an account, and Save at the bottom](../../../assets/shots/orgs-settings-org.png)

## Opening it

- **Settings** in the header of the sidebar's Organizations section. It opens on the organization
  you're looking at: the view's, else the selected card's, else the last one you used.
- The [command palette](/board/palette/) has **Settings**, **Open \<org\> settings** for each
  organization, and **Search folders**.

## The nav

The left column lists the pages: **General** and **Keyboard shortcuts** (see
[Changing shortcuts](/reference/keys/#changing-shortcuts)) under *desk*, then every organization, a
nested one indented under its outer one. The dot says how the organization's `desk.toml` reads:

| Dot | Means |
|---|---|
| green | it reads and has accounts |
| orange | it doesn't read (a TOML error); the row says *can't read* |
| grey | no accounts yet; the row says *no accounts* |

A page you changed says *edited*; a nested organization says *in \<outer\>*. The bottom of the nav
shows the desk version that runs.

## Saving

The bar at the bottom counts the unsaved changes and says which file the page saves. You can move
between pages: each keeps its edits until you save or discard.

- **Save** (<kbd>Ctrl</kbd>+<kbd>S</kbd>) writes every page you changed, the one shown first, and
  closes the dialog. A page that can't be saved is shown with the reason in the bar.
- **Discard** drops every page's changes.
- <kbd>Esc</kbd> or **×** with unsaved changes first turns the bar orange and asks; <kbd>Esc</kbd>
  again closes without them.

<figure class="cut">

![The settings' bar: "No changes · saves ~/Work/Acme/.desk/desk.toml; comments in it are not kept", and Save with Ctrl+S](../../../assets/shots/orgs-settings-org-bar.png)

<figcaption>The bar names the file the page writes.</figcaption>
</figure>

:::caution
Saving rewrites the `desk.toml` from what it read. Keys the dialog doesn't show are kept, but
comments in the file are not. If you keep a commented `desk.toml` by hand, edit it by hand.
:::

## General

![The General page: the two language fields, the search folder ~/Work with depth 2, and the preview of the organizations it finds](../../../assets/shots/orgs-settings-general.png)

### Languages

<figure class="cut">

![The fields "Cards and tickets in" and "Claude speaks with you in", both English](../../../assets/shots/orgs-settings-general-langs.png)

<figcaption>The languages new cards start with. Each card can change its own.</figcaption>
</figure>

- **Cards and tickets in**: what Improve with Claude, tickets and what Claude writes on the card
  (status reasons, ticket titles, commit messages unless the repository says otherwise) are
  written in.
- **Claude speaks with you in**: the language of the card's conversation.

Both are English until you change them.

### Text size

<figure class="cut">

![Text size: − 100% +, and "Terminals and the session panel · Ctrl+= bigger, Ctrl+- smaller, Ctrl+0 back to 100%"](../../../assets/shots/orgs-settings-general-zoom.png)

<figcaption>The text size, at 100%.</figcaption>
</figure>

How big the text of the terminals (a card's Claude Code terminal and the servers' panes) and of the
session panel is, from 50% to 300%. **−** and **+** change it by 10% and it counts at once, without
**Save**. Anywhere in desk, <kbd>Ctrl</kbd>+<kbd>=</kbd>, <kbd>Ctrl</kbd>+<kbd>-</kbd> and
<kbd>Ctrl</kbd>+<kbd>0</kbd> (back to 100%) do the same. A terminal's columns and rows follow the
text, so a bigger text gives its program fewer of them.

### Search folders

The folders desk searches for organizations, top to bottom: when two give the same name, the
higher one wins. Each row has:

<figure class="cut">

![A search folder row: the path ~/Work, "finds 5 · Acme, Globex, Initech, scratch, Billing", depth 2 with − and +, and the two switches](../../../assets/shots/orgs-settings-general-folder.png)

<figcaption>One search folder. Under the path, what it finds.</figcaption>
</figure>

- **Folder**: a full path, or one from `~`.
- **Depth**: − and + from 0 to 6. Level 1 is the folder's subfolders; deeper levels count only
  folders with a `desk.toml`.
- **Only with desk.toml**: subfolders without a `desk.toml` aren't organizations.
- **Folder is an org**: the folder itself is an organization when it has a `desk.toml`.
- **×** removes the folder.

**+ Add folder** adds a row (depth 1, *Only with desk.toml* on).

The **Preview** under the rows scans the folders as you edit them and shows the organizations
they give: a new one says where it comes from, a nested one shows its path. With *Only with
desk.toml* on, the subfolders it leaves out are listed as skipped (**Show all** past six).

<figure class="cut">

![With "Only with desk.toml" on: the preview shows Acme, Globex, Initech and Billing · Acme/billing, and "Skipped, no desk.toml: scratch"](../../../assets/shots/orgs-settings-only-preview.png)

<figcaption>Turning on Only with desk.toml: scratch has none, so it's skipped.</figcaption>
</figure>

Save refuses a depth that isn't 0 to 6, a path that isn't a folder, and an empty list (desk needs
one folder to find organizations). Saving the folders also reloads the organizations.

## An organization's page

The page's title is the organization; under it, the path of its `desk.toml`. Each account is a
card: its kind's tile (GH, JI, BW…), its name and kind, and a line with where it points and where
its token comes from. **Edit** opens it; one is open at a time.

<figure class="cut">

![Acme's Jira account open: Name, URL, Email and Projects fields, the API token's source set to Environment variable with DESK_DEMO_TOKEN, and Remove](../../../assets/shots/orgs-settings-account.png)

<figcaption>An account open: its fields two by two, where its token comes from, and Remove.</figcaption>
</figure>

A card says **New** or **Edited** until you save. The buttons under the cards add an account of
each kind:

<figure class="cut">

![The buttons + Vault, + GitHub, + Jira, + Bitbucket, + GitLab and + Nagios](../../../assets/shots/orgs-settings-org-add.png)

<figcaption>Add a vault or an account.</figcaption>
</figure>

What each kind's fields mean, and where tokens come from, is in [Accounts](/orgs/accounts/)
and [Vaults](/orgs/vaults/). Under the buttons, **Servers** has the **Show the server's login
message** switch (`clear_login = false`: the banner and message of the day stay above a pane's
first prompt, see [Command blocks](/servers/panes/#command-blocks)), the organization's servers
file and **Import from Ásbrú** ([Import from Ásbrú](/servers/asbru/)).

Save refuses a vault without a name, two vaults with the same name, and a token from a vault the
organization doesn't have.

When the `desk.toml` doesn't read, its page says why in the bar ("… — fix it by hand") and has
no Save: fix the file by hand, then open the settings again.
