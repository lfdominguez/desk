<CardGrid>
	<Card title="A card is a session" icon="list-format">
		Every card runs its own Claude Code session in the organization's folder, under its account. The
		card shows what it's doing: working, your turn, blocked, done.
	</Card>
	<Card title="Requests, worked out" icon="pencil">
		Say what to do in a sentence. Haiku reads the code and the tickets and turns it into a title, a
		full first message, labels, links and a due date.
	</Card>
	<Card title="Everything the work depends on" icon="seti:git">
		Pull and merge requests, Jira and GitHub tickets, CI runs and Nagios alerts, live on the cards,
		through each organization's own accounts.
	</Card>
	<Card title="Servers, with a Claude beside you" icon="seti:shell">
		SSH panes you share with an infra Claude that asks before every change. A card hands it server
		work, and each card gets a session of its own.
	</Card>
	<Card title="Drawings you and Claude share" icon="pen">
		Excalidraw diagrams per organization and per card. Claude draws when you ask, suggests the
		rest for you to approve, and every edit undoes.
	</Card>
</CardGrid>
