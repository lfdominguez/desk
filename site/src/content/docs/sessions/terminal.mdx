title: The terminal

Sometimes you want Claude Code itself: its slash commands, its own prompts, its permission
dialogs. desk can open a card's session in the full Claude Code terminal (its TUI), inside desk's
window. It's the same session as the conversation: it resumes where the conversation is.

## Opening it

- On the board, select the card and press <kbd>T</kbd>.
- Right-click the card and pick **Claude Code terminal**.
- In the card's panel or full window, click the terminal icon in the header.

The terminal opens over the board. Its header shows the card's key and title, its folder, the
account it runs under, and three buttons: **Remote**, **Chat** and **Close**.

## What happens

- desk lets go of the conversation's own Claude process first, so the session never runs twice.
  The terminal runs `claude` in the card's folder, under the organization's account, and resumes
  the card's session (or starts it under the card's session id, if it never ran).
- The card turns to your turn, with "In its terminal" as its status line. Under
  [Agent Sessions](/sessions/full-window/#agent-sessions), its row has a green terminal icon.
- While the terminal is open, the panel's message box won't send: desk says the card "is open in
  its terminal: write there, or close it first", and shows you the terminal.

## Remote Control

To go on with the card's session from claude.ai/code or the Claude app on your phone, turn on
Claude Code's [Remote Control](https://code.claude.com/docs/en/remote-control) for the card:

- click **Remote** in the terminal's header, or
- right-click the card and pick **Turn on Remote Control** (<kbd>R</kbd>).

desk then (re)starts the card's terminal with `--remote-control`, named after the card's key and
title. Claude Code shows the session's link and a QR code in the terminal; the header's button
turns green, **Remote · on**. What you or Claude write on either side shows on the other.

- It stays on for the card: every time its terminal opens, it connects again.
- **Remote · on** (or **Turn off Remote Control** in the menu) turns it off and restarts an open
  terminal without it.
- Restarting the terminal cuts a turn Claude is in the middle of; the session resumes where it was.
- Only the terminal serves it: Claude Code offers Remote Control in its TUI, not to the process
  behind the conversation.
- It needs the organization's Claude account to be signed in to claude.ai (Pro, Max, Team or
  Enterprise), not an API key.

## Keys

A terminal takes every key, <kbd>Esc</kbd> included, for Claude Code. desk's own keys don't work
while you type there, except the text size's: <kbd>Ctrl</kbd>+<kbd>=</kbd> bigger,
<kbd>Ctrl</kbd>+<kbd>-</kbd> smaller, <kbd>Ctrl</kbd>+<kbd>0</kbd> back to 100% (see
[Settings](/orgs/settings/#text-size)). Claude Code then gets fewer or more columns and rows.

- <kbd>Ctrl</kbd>+<kbd>V</kbd> with an image on the clipboard saves it and pastes its path, which
  Claude Code attaches. <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd> (<kbd>⌘</kbd>+<kbd>V</kbd> on macOS) pastes the clipboard's text.
- The mouse wheel scrolls back through what the terminal showed, unless Claude Code takes the
  wheel itself.

## It keeps running

The terminal keeps running while you look at something else: the board, another card, the
servers. To go back to it, press <kbd>T</kbd> on the card again, or click its row under Agent
Sessions.

- **Chat** shows the card's session in the [full window](/sessions/full-window/). The
  terminal keeps running.
- **Close** hangs the terminal up. Typing `/exit` in Claude Code does the same. The card's status
  line then says "Terminal closed" (or "Claude exited in its terminal" if Claude Code failed).

After that, the next message from the panel starts the conversation's process again, on the same
session.
